📖 Instrucciones de Uso

  1. Para OBS Studio:
    Servidor: rtmp://localhost:1935/live
    Clave de stream: mycamera (o la que prefieras)
  2. Para FFmpeg:
    ffmpeg -i [fuente] -c:v libx264 -c:a aac -f flv rtmp://localhost:1935/live/mycamera
  3. Para cámaras IP: Configura la URL RTMP en la cámara usando los datos de arriba
  4. Visualización: Una vez iniciado el stream, haz clic en "Cargar Stream" en esta página
  5. Múltiples streams: Usa diferentes claves para múltiples cámaras simultáneas
